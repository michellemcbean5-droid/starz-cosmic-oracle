## Typography

| Level | Size | Weight | Usage |
|-------|------|--------|-------|
| Title | 24-28px | Bold | Screen titles |
| Subtitle | 14-16px | Regular | Descriptions |
| Body | 14-15px | Regular | Paragraphs |
| Caption | 11-13px | Regular | Labels, metadata |
| Card Title | 18-20px | Bold | Section headers in cards |

## Spacing System

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tight gaps |
| sm | 8px | Small gaps |
| md | 12px | Medium gaps |
| base | 16px | Standard padding |
| lg | 20px | Large padding |
| xl | 24px | Section spacing |
| 2xl | 32px | Major sections |

## Border Radius

| Token | Value | Usage |
|-------|-------|-------|
| sm | 4px | Small buttons |
| md | 8px | Inputs, small cards |
| lg | 12px | Cards |
| xl | 16px | Large cards |
| full | 9999px | Circular elements (avatars, badges) |

## Shadows

Cards use subtle elevation with shadowOpacity 0.3-0.4 and colored borders to maintain the cosmic glassmorphism effect.

## Animation

| Effect | Duration | Easing |
|--------|----------|--------|
| Star twinkle | 2000-5000ms | inOut(Easing.ease) |
| Card press | 150ms | easeOut |
| Screen transition | 300ms | easeInOut |

## Dark Mode

The app is exclusively dark-mode. All text uses light tones against dark cosmic backgrounds. No light mode is planned.
